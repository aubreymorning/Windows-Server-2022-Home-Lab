# Windows Server 2022 Home Lab

Hands-on Windows Server 2022 home lab built in VirtualBox to practice core Windows Server administration skills.

## Technologies Used

- Windows Server 2022
- Active Directory Domain Services (AD DS)
- Group Policy
- DNS
- DHCP
- File and Storage Services
- NTFS Permissions
- VirtualBox

## Labs

| Lab | Description |
|------|-------------|
| Lab 01 | Active Directory User Management |
| Lab 02 | Group Policy Management |
| Lab 03 | DNS Troubleshooting |
| Lab 04 | DHCP Configuration |
| Lab 05 | File Server & NTFS Permissions |

## Skills Demonstrated

- Active Directory administration
- User and Group management
- Group Policy configuration
- DNS management and troubleshooting
- DHCP scope configuration
- SMB file sharing
- NTFS permissions
- Windows Server administration
