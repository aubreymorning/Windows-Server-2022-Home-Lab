# Lab 01 - Active Directory User Management

## Objective
Create and manage users, groups, and an Organizational Unit (OU) in Active Directory.

## Skills Practiced
- Active Directory Users and Computers
- Organizational Units (OUs)
- User account creation
- Security groups
- Group membership management

## Outcome
Successfully created a Finance OU, user accounts, and security groups, then assigned users to the appropriate groups.
